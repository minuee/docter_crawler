#### Installation

requires [Node.js](https://nodejs.org/) v20.12+ to run.
Install the dependencies and devDependencies and start the server.

```sh
cd *application Installed folder*
npm install
node api.worker
```

> End Point: using postman for tseting.

```sh
127.0.0.1:1100
```
